# Échelle des crèmes

Chaque gris de l'interface de Bluloco Light est remplacé par un ton crème, en
conservant leur ordre de luminosité. Le texte (`#383a42`, `#a0a1a7`), les couleurs
d'accent et les couleurs du terminal restent ceux de Bluloco Light.

| Bluloco Light | Crème     | Emploi principal                                          |
| ------------- | --------- | --------------------------------------------------------- |
| —             | `#fffcf4` | Champs de saisie, listes déroulantes, notifications       |
| `#f9f9f9`     | `#fdf9ee` | Fond de l'éditeur, des panneaux, barre latérale, onglet actif |
| `#f5f5f5`     | `#f8f3e3` | Sélection inactive dans les listes                        |
| `#eeeeee`, `#e8e8e8` | `#f3edda` | Barre de débogage, centre de commandes, widgets    |
| —             | `#f4eedd` | Barre d'onglets, onglets inactifs                         |
| —             | `#f1ebd8` | Onglet survolé                                            |
| —             | `#f0e9d6` | Règles verticales, repères d'indentation                  |
| `#f1f1f1`, `#ebebeb` | `#efe8d3` | Barre d'activité, barre d'état, ligne courante, survol des listes, en-têtes de section |
| `#ebebeb`     | `#ede6d0` | Onglet actif « modern »                                   |
| —             | `#ebe4cf` | Séparateurs d'onglets                                     |
| `#d1d1d1`     | `#e0d8c1` | Bordure de la barre latérale, ombres                      |
| —             | `#e0d7bf` | Repère d'indentation du bloc courant                      |
| `#d5d7d8`     | `#e3dbc4` | Bordures, boutons secondaires, blocs de code              |
| `#c2c4c7`     | `#d8cfb5` | Barre de titre                                            |
| `#bdbbbb`     | `#d0c7ad` | Bordure de cellule de notebook                            |
